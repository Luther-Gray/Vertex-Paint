# 👁️ Vertex Paint
![alt text](./images/vertexPaintIcon.png)
Vertex Paint is a Blockbench Plugin that finally delivers the missing feature of, well, Vertex Painting. It features everything from brush sizes, falloff control, and multi-vertex coloring!

# Two Tools
Vertex Paint comes with two tools that should be able to handle any project you throw at them.

1. The Vertex Paint Tool: This allows you to color particular vertices depending on your brush size. The Softness of your brush acts as a falloff, and Opacity controls the Alpha of that vertex.

2. The Vertex Paint Bucket: Like you'd expect, this tool will color all selected verticies according to your selected Color & Opacity settings in one click.

## 🖥️🌐 Install
Installation is the same as every other Blockbench Plugin. Simply grab it from the Plugin Store, or Load the Plugin from the Javascript (`vertex_paint`) file.
